# fifo_clipboard

A lightweight clipboard manager that uses FIFO (First In, First Out) queues for efficient clipboard history management.

## Features

- Simple FIFO-based clipboard history
- Lightweight and fast
- Cross-platform support (Linux, macOS, Windows)
- Command-line interface
- Configurable history size
