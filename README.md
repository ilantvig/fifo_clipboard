# FIFO Clipboard

Утилита для Windows: очередь буфера обмена. Когда режим FIFO включён, **Ctrl+V** вставляет
не текущее содержимое буфера, а самый старый элемент очереди — удобно для последовательной
вставки нескольких заранее скопированных фрагментов.

## Как это работает

1. Копируете фрагменты в любом порядке и в любых приложениях: `A`, `B`, `C`.
2. Каждый текстовый фрагмент попадает в очередь (иконка в трее показывает `3`).
3. Нажимаете Ctrl+V — вставляется `A`, затем `B`, затем `C`. Счётчик уменьшается.
4. Когда очередь пуста, Ctrl+V снова работает как обычная вставка.

## Возможности

- Очередь до **64** текстовых фрагментов: до **2 МиБ** на элемент и **16 МиБ** суммарно.
  При переполнении вытесняются самые старые элементы.
- Подряд идущие дубликаты не добавляются (повторное копирование того же текста).
- Иконка в трее: число элементов, цвет состояния — зелёный (FIFO активен),
  серый (приостановлен, показывается `-1`). Всплывающая подсказка дублирует состояние.
- Меню трея: приостановка, звуковые уведомления, очистка очереди, параметры, выход.
- Настройки сохраняются между запусками.
- Одна копия приложения **в сеансе пользователя**.

## Горячие клавиши

| Комбинация | Действие |
|---|---|
| Ctrl+C / Ctrl+X / «Копировать» | обычное копирование; в FIFO-режиме текст попадает в очередь |
| Ctrl+V | в FIFO-режиме — вставка самого старого элемента; при пустой очереди — обычная вставка |
| Alt+Shift+F | вкл / выкл FIFO-режим |
| Alt+Shift+Z | удалить последний скопированный элемент очереди (только при включённом FIFO) |
| Alt+Shift+Q | выход |

В очередь попадает **любое** изменение буфера обмена, а не только Ctrl+C: вырезание,
копирование из контекстного меню, копирование другим приложением.

## Настройки

Файл `fifo_clipboard.ini`:

```ini
[General]
FifoMode=0
Sounds=0
```

Путь выбирается при запуске:

1. Каталог рядом с exe — если он доступен для записи (проверяется пробным файлом).
2. Иначе `%APPDATA%\FifoClipboard\fifo_clipboard.ini`.
   Если найдётся старый ini прямо в корне `%APPDATA%`, он переносится автоматически.
3. Если и это недоступно — `%TEMP%`.

Путь всегда абсолютный: это важно, иначе API профилей Windows ищет ini в `%SystemRoot%`.

## Ограничения

- **Только текст.** В очередь попадает `CF_UNICODETEXT`; файлы, изображения и другие
  форматы игнорируются. Текст больше 2 МиБ в очередь не добавляется.
- **Исходное содержимое буфера не восстанавливается.** После FIFO-вставки в буфере
  остаётся вставленный элемент, а не то, что было там до этого.
- **Очередь живёт только в памяти** и теряется при выходе из приложения.
- **Окна с повышенными правами.** Копирование *из* таких окон работает: текст
  попадает в очередь как обычно. Вставка *в* такие окна — обычная: Windows
  блокирует синтетический ввод (UIPI), поэтому Ctrl+V там не перехватывается
  и вставляет текущее содержимое буфера, а не элемент очереди. Чтобы FIFO-вставка
  работала и в таких окнах, запускайте утилиту с тем же уровнем прав.
- **История буфера обмена (Win+V).** Каждая FIFO-вставка меняет системный буфер,
  поэтому попадает в историю Windows.
- **Клавиатурный хук.** Windows может молча снять низкоуровневый хук, если его
  обработчик долго не отвечает (например, приложение-владелец буфера зависло).
  В этом случае FIFO-вставка перестаёт работать до перезапуска утилиты.

## Требования

- **Windows 10 / 11** — основной сценарий, per-monitor DPI v2.
- Формально минимум — **Windows 7 SP1** (из-за `MOD_NOREPEAT` у горячих клавиш).
  На версиях старше Windows 10 1607 используется запасной путь определения DPI,
  масштабирование иконки может быть менее точным. Работа на Windows 7/8.1
  не проверялась.

## Сборка

Исходники в `src\`, тесты в `tests\`. Готовый скрипт:

```bat
build.bat              :: приложение (clang / llvm-mingw)
build.bat msvc         :: приложение (MSVC)
build.bat tests        :: тесты (clang) + запуск
build.bat msvc-tests   :: тесты (MSVC) + запуск
build.bat asan         :: тесты под ASan/UBSan + запуск
```

Предупреждения трактуются как ошибки (`-Werror` / `/WX`).
Все бинарники складываются в `build\` (каталог добавлен в `.gitignore`).
Убедитесь, что каталог `build\` существует или выполните команду:
```bat
if not exist build mkdir build
```

### Вручную

clang / llvm-mingw:

```bat
clang -std=c11 -Wall -Wextra -O2 -D_WIN32_WINNT=0x0A00 -DNTDDI_VERSION=0x0A000004 ^
  -Isrc src\main.c src\fifo_queue.c src\app_logic.c src\settings.c src\clipboard.c ^
  -o build\fifo_clipboard.exe -mwindows -luser32 -lgdi32 -lshell32 -ladvapi32
```

gcc (MinGW):

```bat
gcc -std=c11 -Wall -Wextra -O2 -D_WIN32_WINNT=0x0A00 -DNTDDI_VERSION=0x0A000004 ^
  -Isrc src\main.c src\fifo_queue.c src\app_logic.c src\settings.c src\clipboard.c ^
  -o build\fifo_clipboard.exe -mwindows -luser32 -lgdi32 -lshell32 -ladvapi32
```

Без `-mwindows` при запуске будет открываться консольное окно.

MSVC (Developer Command Prompt):

```bat
cl /nologo /W4 /utf-8 /std:c11 /Isrc /D_WIN32_WINNT=0x0A00 /DNTDDI_VERSION=0x0A000004 ^
  /Fobuild\ /Fdbuild\ src\main.c src\fifo_queue.c src\app_logic.c src\settings.c src\clipboard.c ^
  /link user32.lib gdi32.lib shell32.lib advapi32.lib /SUBSYSTEM:WINDOWS /OUT:build\fifo_clipboard.exe
```

`/utf-8` обязателен: в исходниках есть русские строковые литералы.

## Тесты

```bat
build.bat tests
```

Покрыты очередь (порядок, лимиты, вытеснение, дедупликация, откат владения, отказ
аллокации), чистая логика (перехват, классификация обновлений буфера с учётом
wrap-around, формат иконки, план вставки) и настройки.

Интеграционный тест с реальным буфером обмена (нужна интерактивная сессия):

```bat
build.bat tests -DINTEGRATION_TESTS
```

> Внимание: интеграционный тест перезаписывает содержимое вашего буфера обмена.

Проверка памяти:

```bat
build.bat asan
```
